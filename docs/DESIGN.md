Исход 1: 

1\. Программа сортирует выбранную заранее папку. (Которую пользователь выбрал в пункте 3).

2\. Если программа смогла валидировать папку, наше приложение создаёт несколько папок в которые будет сортировать файлы по типу: Все файлы с расширением .png, .jpg, .ico отправляются ---> Photo\_folder (которая создаётся при первой итерации сортировки.)

2.1 При успешной сортировки выводим: Сортировка прошла успешно продолжить или выйти? (1 - продолжить, 2 - выйти.)

3\. В случае если приложение не находит нужную папку, выкидываем ошибку в консоль и возвращаем в Меню.

3.1 (При большом желании, если я не устану добавим логирование ошибок через XUnit тесты, либо напишим обычно Single-test.)



\---



Исход 2:

1\. Мы выводим информацию следующим образом:

Код был написан: (Моя ссылка на профиль)

Инструкция по использованию: (Ссылка на README.md на GitHub)

Статистика вашей сортировки: Количество сортированных файлов: {AllSortItems\_counter}

2\. Нажмите что бы продолжить … (Ждём ввода пользователя)

Исход 3:

1\. Появляется сообщение в консоли вставьте путь к вашей сортировочной папке:

2\. Пользователь вводит путь и сортированная папка записывается.

3\. Если пользователь ввёл недействительный путь кидаем ошибку.

4\. Возвращаем в меню.

\--- Methods ---

1\. For class: sort

\- start\_sort (Запуск сортировки.)

\- check\_folder\_path (валидация пути папки, которую пользователь выбрал заранее.)

\- realize\_sort (реализуется сортировка)

\-- folder\_create (Создаёт папки для сортировки.)

\--- created\_folder\_check (Проверка папок которые мы создали использую folder\_create. Если папки созданы то не делаем дубликаты.)

\- sort\_message (succes or failed)

2\. For class: program\_info

\- show\_info\_message (Показывает разделы которые написаны в исходе 2.)

\- allSortItems\_count (подсчитывает все сортированные файлы)

3\. For class: sort\_foldersa

\- sort\_folder\_picker (Этот метод реализует выбор папки для сортировки.)

\- check\_user\_folder (Этот метод будет проверять путь, который ввёл пользователь)

\- user\_folder\_message (Этот метод выводит сообщение об успешной или провальной валидацией папки)

4\. For class: col\_config

\- color\_pick (Этот метод считывает выбор пользователя)

\- color\_change (Этот метод как раз таки меняет цвет)

\- color\_save (Сохраняет цвет в Json\_cfg.)

5\. For class: program

\- current\_sort\_folder - хранит текущую папку сортировки.

\- folder\_create\_list - содержит папки которые нужно будет создать при начале сортировки.

\- Json\_folder - хранит JSON файл с конфигом настроек и AllSortItems\_Counter.

\- default\_folder - (задаёт папку по умолчанию через APPDATA/user/...)

6\. For class: Menu

\- render\_menu - применяет настройки цветов и выводит меню в консоль.

\- user\_input - считывает выбор в меню.
